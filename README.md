# watchtogether

Совместный просмотр видео (VK Видео, YouTube, Vimeo, Twitch, прямые .mp4) с синхронизацией, чатом и статистикой.

## Запуск

```bash
npm install
npm run build          # собрать фронтенд в dist/
TURSO_DATABASE_URL=libsql://... TURSO_AUTH_TOKEN=... npm start
```

Локально без Turso можно использовать файл: `TURSO_DATABASE_URL=file:local.db npm start`.
Без базы регистрация и вход не работают (аккаунт обязателен для просмотра).

Разработка: `npm run dev` (Vite на 5173 + сервер на 3001).

## Комнаты

- Сайт запоминает последнюю комнату: открыли `/` — попали в неё же, а не в новую.
- Код комнаты виден в шапке (нажатие копирует ссылку). Через «+» можно перейти в другую комнату по коду или ссылке.

## Если видео из VK не запускается

Порядок, в котором стоит проверять (самые частые причины — первые):

1. **Встроенный браузер Telegram / Instagram / VK.** Там плеер VK часто не работает вообще. Нажмите «⋯» → «Открыть в браузере» (Safari или Chrome).
2. **Safari на iPhone:** Настройки → Safari → выключить «Не отслеживать» (Prevent Cross-Site Tracking). VK в своей документации прямо пишет, что из-за этой защиты виджет не работает. Либо используйте Chrome.
3. **Блокировщик рекламы** (AdGuard, uBlock и т.п.) — отключить для сайта: он режет скрипт плеера `videoplayer.js`.
4. **VPN.** VK заблокирован в части стран (без VPN не откроется) и одновременно не любит адреса VPN/датацентров (с VPN может не открываться). Попробуйте оба варианта. Сайт сам перебирает три адреса VK (`vkvideo.ru`, `vk.com`, `vk.ru`) — иногда доступен только один из них.
5. **Приватное видео / «доступно по ссылке».** Откройте видео в VK → «Поделиться» → «Экспортировать» и вставьте в сайт весь код `<iframe …>` целиком — в нём есть ключ доступа (`hash`), без которого плеер показывает «видео недоступно».
6. **Не стартует у второго человека.** Телефоны запрещают запускать видео без касания по экрану. Сайт сначала пытается стартовать без звука, потом показывает кнопку «Включить звук» или «Смотреть вместе» — одно нажатие. Если и это не сработало, нажмите ▶ прямо на плеере — вы автоматически догоните комнату.

Геоблокировку самого VK (видео недоступно в стране) сайт обойти не может — это решается только VPN на стороне зрителя.
